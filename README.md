# Wordle

A multiplayer Wordle game built with Streamlit.

## Features

- Interactive word guessing game with 6 attempts
- Color-coded feedback (green=correct, yellow=present, gray=absent)
- Physical and on-screen keyboard support
- Admin panel for word management
- Mobile-responsive design
- **NEW**: Configurable keyboard appearance for mobile portrait mode

## Mobile Keyboard Configuration

You can now customize the keyboard keys and spacing in portrait mode on mobile devices! 

See [MOBILE_KEYBOARD_CONFIG.md](MOBILE_KEYBOARD_CONFIG.md) for detailed instructions on how to configure:
- Key spacing/gap
- Key size (height, width)
- Font size
- Padding

## Running the Application

```bash
streamlit run wordle.py
```

## Requirements

- Python 3.x
- Streamlit
